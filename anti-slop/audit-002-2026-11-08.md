# UI Audit 002

Date: 2026-11-08
Mode: AFTER
Scope: `src/components/registration/NewRegistrationView.jsx` (Form Registrasi Dokumen Baru)

Audit kode antislop terhadap komponen formulir registrasi dokumen baru untuk memastikan tampilan bersih, profesional, bebas dari pola *generic AI slop*, serta memenuhi standar aksesibilitas WCAG AA dan interaksi keyboard.

## Findings

### 1. HIGH - Karakter em dash (`—`) digunakan pada label opsi pejabat (R-02)

`src/components/registration/NewRegistrationView.jsx:739,768,788` menggunakan karakter em dash (`—`) untuk memisahkan nama karyawan dan jabatan pada elemen `<option>` (contoh: `{emp.name} — {emp.position}`). Aturan R-02 melarang em dash dalam teks UI buatan AI dan mewajibkan pemisah alami seperti tanda hubung berjarak (` - `), kurung, atau titik dua.

### 2. HIGH - Area unggah berkas (file dropzone) tidak memiliki indikator fokus keyboard dan accessible label (R-32, R-39)

`src/components/registration/NewRegistrationView.jsx:658-667` menggunakan `<input type="file" className="absolute inset-0 opacity-0 cursor-pointer w-full h-full" />` tanpa atribut `aria-label`, dan pembungkus dropzone tidak memiliki styling `focus-within:ring-2 focus-within:ring-blue-500`. Pengguna navigasi keyboard (`Tab`) tidak dapat melihat letak fokus saat berada di area unggah dokumen.

### 3. HIGH - Teks redup (muted text) pada tema terang tidak memenuhi standar kontras WCAG AA (R-25)

`src/components/registration/NewRegistrationView.jsx:623,674,696,925,943,956,976,996,1024` menggunakan kelas `text-slate-400` berukuran 10px pada latar belakang putih/terang. Rasio kontras Tailwind `slate-400` (`#94a3b8`) di atas latar putih hanya berkisar 2.56:1, di bawah ambang batas minimal WCAG AA (4.5:1 untuk teks normal). Sebaiknya dinaikkan menjadi `text-slate-500` atau `text-slate-600` pada tema terang.

### 4. HIGH - Tombol toggle pejabat kustom di bawah batas minimal tap target mobile 44px (R-03, R-39)

`src/components/registration/NewRegistrationView.jsx:708-713` merender tombol `⚙️ Sesuaikan Pejabat Penyetuju (Khusus Pengganti / Cuti)` dengan teks kecil `text-[11px]` tanpa padding vertikal (`py`) yang memadai. Pada perangkat layar sentuh/mobile, tinggi sentuh tombol kurang dari standar minimal 44px (R-03).

### 5. MEDIUM - Status berkas terlampir perlu status badge yang lebih ringkas dan teratur (R-09, R-11)

`src/components/registration/NewRegistrationView.jsx:671-690` merender badge ekstensi file (`EXCEL / SPREADSHEET`, `WORD (.DOCX)`, `PDF`) dengan kombinasi warna beragam yang menumpuk di dalam dropzone tanpa batas pemisah visual yang rapi saat nama file panjang.

### 6. LOW - Konsistensi dokumentasi palet badge level ISO (R-31)

`src/components/registration/NewRegistrationView.jsx:523-535` menggunakan 4 warna berbeda untuk masing-masing level dokumen (L1: purple, L2: blue, L3: cyan, L4: emerald). Pemilihan warna ini fungsional untuk pembedaan hierarki piramida ISO, namun perlu dicatat dalam panduan desain agar konsisten dengan tampilan piramida di Dashboard Analytics.

## Resolution Report

All 6 approved items have been resolved and verified with `npm run build`:

1. **Item 1 (R-02) RESOLVED:** Replaced em dashes (`—`) with standard hyphens (` - `) across all approver dropdown options.
2. **Item 2 (R-32, R-39) RESOLVED:** Added `aria-label="Pilih atau seret berkas dokumen resmi"` and `focus-within:ring-2 focus-within:ring-blue-500` to the file dropzone container for full keyboard accessibility.
3. **Item 3 (R-25) RESOLVED:** Upgraded muted text in light mode from `text-slate-400` to `text-slate-500`, elevating contrast ratio from ~2.56:1 to $\ge 4.5:1$ (WCAG AA pass).
4. **Item 4 (R-03, R-39) RESOLVED:** Expanded collapsible custom approver toggle to `min-h-[44px]` with `px-3.5 py-2.5` touch padding and subtle button styling.
5. **Item 5 (R-09, R-11) RESOLVED:** Refactored file attachment card into a cohesive mini-card with document icon, filename truncate, file size, format tag, and quick-cancel (`X`) button.
6. **Item 6 (R-31, R-37) RESOLVED:** Formulated and committed `DESIGN.md` establishing the design dials (`ENERGY 1 / RHYTHM 2 / MOTION 1`) and the ISO 4-tier color architecture.
